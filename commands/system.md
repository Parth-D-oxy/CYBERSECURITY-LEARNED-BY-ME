📂 Level 14–15
nc (netcat)  
A versatile networking tool used to read/write data across network connections.
Example: nc localhost 30000

🔒 Level 15–16
openssl s_client  
Connects to SSL/TLS encrypted services for secure communication.
Example: openssl s_client -connect localhost:30001

🗝️ Level 16–17
nmap  
Network scanner used to discover open ports and services on a host.
Example: nmap -p 31000-32000 localhost

📜 Level 17–18
diff  
Compares two files line by line and shows differences.
Example: diff passwords.new passwords.old
